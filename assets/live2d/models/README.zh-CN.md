# Live2D 模型

> **语言：** 简体中文 · [English](README.md)

把 Cubism 的 `model3.json` 模型文件夹放在这里。

想快速拿一个测试模型，请在仓库根目录执行：

```powershell
.\tools\download_live2d_haru.ps1
```

该脚本会把 Live2D Cubism Web Samples 官方示例中的 `Haru` 模型下载到：

```text
assets/live2d/models/Haru/
```

模型来源：

```text
https://github.com/Live2D/CubismWebSamples/tree/develop/Samples/Resources/Haru
```

再次分发随包附带的模型文件前，请先核对上游 Live2D 示例的许可条款。
